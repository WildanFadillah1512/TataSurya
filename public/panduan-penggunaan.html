Panduan 01

Cara Memulai

1

Buka Aplikasi & Halaman Utama

Buka aplikasi AstroLearn di browser. Kamu akan disambut layar hitam dengan latar bintang bertaburan dan logo AstroLearn di sudut kiri atas.

2

Tekan & Tahan Tombol "HOLD TO START"

Di tengah layar terdapat tombol bulat besar bertuliskan HOLD TO START. Tekan dan tahan tombol tersebut hingga lingkaran progress penuh (100%). Bintang-bintang akan bergerak semakin cepat menunjukkan efek warp.

3

Status Sistem Berubah

Perhatikan teks status di bawah tombol. Status akan berubah dari SYSTEM_IDLE → SYNCING_NEURAL_FLOW → JUMP_AUTHORIZED. Setelah authorized, kamu otomatis diarahkan ke menu utama.

4

Pilih Sektor di Menu System Select

Di halaman System Select, terdapat 3 objek 3D berputar dalam carousel. Gunakan tombol < / >, scroll mouse, atau swipe untuk berpindah antar sektor, lalu klik INITIALIZE LINK untuk masuk.

💡

Pada perangkat mobile, gunakan sentuhan untuk menahan tombol dan swipe untuk navigasi menu. Semua fitur mendukung layar sentuh.

⚡

Panduan 03

Eksplorasi Planet

1

Masuk ke Sektor Exploration

Pilih sektor EXPLORATION dari menu, lalu klik INITIALIZE LINK. Kamu akan masuk ke tampilan 3D tata surya dengan Matahari di tengah dan planet-planet mengorbit.

2

Navigasi Alam Semesta 3D

Gunakan klik kiri + drag untuk memutar pandangan, scroll untuk zoom in/out, dan klik kanan + drag untuk menggeser posisi kamera (pan).

3

Klik Planet untuk Detail Singkat

Klik objek planet mana saja. Kamera akan pindah mendekat dan panel informasi muncul di sisi layar berisi nama, deskripsi, dan fakta singkat.

4

Buka Halaman Detail Planet

Di panel info, klik tombol "Lihat Detail" untuk membuka halaman detail penuh dengan model 3D interaktif, tab Gambaran Umum, Struktur, Atmosfer, Statistik, dan Fakta Unik.

5

Ikuti Kuis di Halaman Detail

Di bagian bawah halaman detail, tersedia tombol Mulai Misi Kuis. Masukkan nama astronautmu, lalu jawab serangkaian pertanyaan untuk mendapatkan skor dan masuk ke papan peringkat.

Panduan 04

Fenomena Alam (Archives)

1

Masuk ke Sektor Archives

Dari menu System Select, pilih ARCHIVES (Sector 09) dan klik INITIALIZE LINK.

2

Pilih Fenomena

Gunakan tombol < / > atau swipe untuk berpindah antar 5 fenomena yang tersedia.

3

Interaksi dengan Slider

Untuk fenomena Gerhana dan Musim, geser slider di bagian bawah untuk mengontrol posisi atau rotasi objek langit secara real-time.

4

Aktifkan Narasi Audio

Klik tombol 🔊 Audio untuk mendengarkan penjelasan fenomena menggunakan Text-to-Speech dalam Bahasa Indonesia.

5

Mode AR (Augmented Reality)

Klik tombol AR untuk mengaktifkan kamera perangkatmu dan melihat simulasi ditampilkan di atas latar kamera nyata.

Panduan 05

Simulasi & Game

Pilih SIMULATION dari menu untuk masuk ke Game Lobby. Terdapat 2 game aktif dan 1 slot terkunci.

PUZZLE DIMENSION

🟣 SPACE MYSTERY

Tebak nama planet atau benda langit dari model 3D yang ditampilkan. Susun huruf-huruf acak menjadi jawaban yang benar. Tersedia 10 level dengan 3 nyawa dan 3 petunjuk (hint 💡).

Cara Main:
Lihat model 3D → Baca petunjuk → Klik huruf yang tersedia → Susun jawaban → Konfirmasi → Level berikutnya.
FLIGHT DIMENSION

🔵 ASTRO ADVENTURE

Pertarungan luar angkasa berbasis kuis! Kendalikan pesawat, tembak musuh, dan kalahkan mereka hanya dengan menjawab pertanyaan astronomi dengan benar untuk menambah skor.

Cara Main:
Gerakkan pesawat (Mouse/Touch) → Tembak musuh → Jawab kuis → Kumpulkan skor → Masuk Leaderboard.
RESTRICTED

🔴 CLASSIFIED

Dimensi ini terkunci. Containment Field masih aktif. Tunggu pembaruan berikutnya untuk membuka akses.

Status: TERKUNCI 🔒

Skor game akan tersimpan ke Papan Peringkat secara otomatis setelah game selesai. Pastikan mengisi namamu agar tercatat!

Panduan 08

Pertanyaan Umum (FAQ)

Model 3D dimuat dari file .glb yang memerlukan koneksi internet. Pastikan internetmu aktif dan coba refresh halaman. Jika masih bermasalah, coba gunakan browser terbaru seperti Chrome atau Firefox.
Fitur audio menggunakan Web Speech API. Pastikan browser mendukung fitur ini (Chrome/Edge direkomendasikan). Jika muncul pesan "Tidak ada suara terdeteksi", coba izinkan browser mengakses sistem suara atau periksa pengaturan suara perangkatmu.
AstroLearn menggunakan rendering 3D berbasis WebGL yang memerlukan GPU memadai. Pada perangkat mobile atau PC lama, performa otomatis dikurangi. Tutup tab browser lain, gunakan Chrome terbaru, dan pastikan tidak ada aplikasi berat yang berjalan bersamaan.
Mode AR memerlukan akses kamera. Pastikan kamu mengizinkan akses kamera di browser saat pertama kali diminta. Jika sudah ditolak, buka pengaturan browser dan ubah izin kamera untuk situs ini menjadi "Allow/Izinkan".
Pastikan kamu memasukkan nama di layar identifikasi sebelum memulai kuis atau game. Skor hanya tersimpan jika nama diisi. Jika masalah berlanjut, periksa koneksi internet karena leaderboard disinkronkan ke server.
Pastikan kamu menekan dan menahan tombol, jangan hanya mengetuk. Tombol ini dirancang dengan interaksi touchstart dan touchend. Jika tidak merespons, coba refresh halaman dan gunakan Chrome terbaru di HP-mu.
